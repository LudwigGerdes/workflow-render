# workflow-render-assets

Bundled n8n node icons, descriptions and subtitle templates plus the Inter faces, with offline loaders for workflow-render.

Part of [workflow-render](https://github.com/LudwigGerdes/workflow-render), which renders workflow and execution JSON to SVG/PNG offline. n8n is the first supported platform. This is an internal workspace library and is not published to npm on its own. Its loaders and the data ship inside the one `workflow-render` package (`workflow-render/core` re-exports the loaders; the data is the package's `data/` directory).
