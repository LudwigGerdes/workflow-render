# Bundled data

This folder holds the data `workflow-render-assets` serves at runtime. **Most of it
is n8n GmbH's work, not this project's, and it is not covered by the MIT
license in the repository root.**

## `<version>/` — n8n-derived bundles

One folder per n8n release the canvas emulates (currently `2.38.1`; the
`EMULATED_VERSION` constant in `src/version.ts` names the active one). Each holds:

| File | What it is | Extracted from |
|---|---|---|
| `icons.json` | node icons: vendor SVGs and small raster icons (inlined as data URIs) from the node packages, `node:<id>` SVGs from n8n's source tree, `fa:*` glyphs resolved to Lucide bodies, and monogram fallbacks | `n8n-nodes-base@<version>`, `@n8n/n8n-nodes-langchain@<version>` (npm), `n8n-io/n8n` tag `n8n@<version>` (`packages/frontend/@n8n/design-system/src/components/N8nIcon/nodes`), Lucide |
| `descriptions.json` | trimmed node descriptions (display names, properties, options, `displayOptions`, defaults, credential names) used by the inspector | `dist/types/nodes.json` in the same npm packages |
| `subtitles.json` | node subtitle expressions and the parameter defaults they need | the same `nodes.json` |
| `glyphs.json` | Lucide glyph bodies and the `fa:* -> lucide` mapping | `@iconify-json/lucide` (Lucide, ISC) |
| `font-metrics.json` | glyph advances measured in a browser from a live n8n canvas | measurement, see the file's `source` field |
| `meta.json` | extraction record: versions, sources, counts, fallbacks | generated |

They are regenerated by `scripts/extract.ts`:

```bash
pnpm --filter workflow-render-assets extract <n8n-version>   # dev-time, networked
```

**License.** The icons, `node:` SVGs, node descriptions and subtitle
expressions are the work of n8n GmbH and are distributed under the
[n8n Sustainable Use License](https://github.com/n8n-io/n8n/blob/master/LICENSE.md).
They are redistributed here unmodified apart from trimming and script-stripping,
so that the canvas can render without an n8n instance. They are **not** covered
by this repository's MIT license. Vendor icons (Slack, Airtable, Notion, …) are
trademarks of their respective owners and are shown only to identify the
service a node integrates with. Lucide glyphs are ISC-licensed
(https://lucide.dev).

**The tool runs without these files.** If a version folder, or any file in it,
is missing, the loaders resolve to an empty catalogue: every node renders as an
initials tile, subtitles are blank, and the inspector shows a node's
parameters as stored with a "no description available" notice. Nothing
crashes. See `THIRD_PARTY_NOTICES.md` in the repository root.
