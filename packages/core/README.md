# workflow-render-core

Pure parse → layout → render pipeline that turns n8n workflow or execution JSON into a deterministic SVG. No DOM, no network.

Part of [workflow-render](https://github.com/LudwigGerdes/workflow-render), which renders workflow and execution JSON to SVG/PNG offline. n8n is the first supported platform. This is an internal workspace library and is not published to npm on its own. It is published inside the one `workflow-render` package as the subpath `workflow-render/core`.
