# workflow-render-element

<workflow-render>: a read-only web component that renders n8n workflow and execution JSON as an n8n-style canvas, offline.

Part of [workflow-render](https://github.com/LudwigGerdes/workflow-render), which renders workflow and execution JSON to SVG/PNG offline. n8n is the first supported platform. This is an internal workspace library and is not published to npm on its own. Its build output ships inside the one `workflow-render` package at `dist/element/` (subpath `workflow-render/element`).
